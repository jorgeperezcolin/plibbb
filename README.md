# PLI 3B — Predictive Location Intelligence para Tiendas 3B

Demo ejecutiva en Streamlit para mostrar una maqueta funcional de PLI/DOS aplicada a decisiones territoriales de Tiendas 3B.

## Instalación

```bash
pip install -r requirements.txt
```

## Ejecución

```bash
streamlit run app.py
```

## Archivos

- `app.py`: aplicación completa en Streamlit con datos sintéticos embebidos.
- `requirements.txt`: dependencias necesarias.

La aplicación no depende de APIs externas.
